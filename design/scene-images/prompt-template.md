# Scene Image Prompt Template

Use this template for generating Mister F scene images.

```text
Use case: illustration-story
Asset type: pre-generated Mister F scene image for chat, quiz, writing, or speaking prompts

Primary request:
Create a square four-panel wordless comic illustration for an English-learning activity.

Story:
<Describe the situation as a simple sequence with a beginning, problem, reaction, and resolution.>

Panel sequence:
Panel 1: <setup>
Panel 2: <problem or change>
Panel 3: <reaction or attempt>
Panel 4: <resolution or next-step cue>

Pedagogical purpose:
The image should help a learner <describe a sequence / write a short story / answer comprehension questions / practice target vocabulary / order events / explain a problem and solution>.

Characters:
<Describe character variety and roles. Keep characters consistent and natural. Avoid stereotypes.>

Composition:
Use a clean 2x2 comic grid with four equal panels and simple gutters. Read order should be left to right, top to bottom. Keep the same characters visually consistent across panels. Make each panel show a distinct moment.

Style:
Clean 2D cartoon illustration matching the Mister F roleplay avatars: friendly English workbook style, rounded expressive characters, crisp outlines, bright natural colors, light simple shading, classroom-safe, polished but not overly detailed.

Strict constraints:
No readable text anywhere in the image. No letters, numbers, captions, speech bubbles, logos, menus, signs, labels, posters, readable writing on papers, or watermarks. Do not label the panels.

Quality checklist:
- The four panels communicate a clear story without text.
- The learner can infer who, where, what happened, and what might happen next.
- The image works at 720x720.
- The characters and setting feel inclusive and varied.
- The image is safe for classroom use.
```

## Optional Variants

For quiz prompt images, add:

```text
The image should include 3-5 visible details that can be used in multiple-choice or open-answer questions.
```

For speaking prompts, add:

```text
The image should invite the learner to describe the scene aloud using simple present, present continuous, or past tense.
```
