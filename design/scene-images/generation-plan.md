# Scene Image Generation Plan

This tracker plans the first 50 curated Mister F scene images.

The working cadence is 5 images per batch. Each new batch should normally include:

- 3 four-panel wordless stories;
- 1 two-panel contrast or before/after image;
- 1 single-panel situation image.

Batch 1 was generated before this mix was defined, so it contains five four-panel stories. Starting with Batch 2, the standard mix above should apply.

## Format Definitions

- `four_panel_wordless_story`: a 2x2 comic sequence with setup, problem/change, reaction/attempt, and resolution/next-step cue.
- `two_panel_contrast`: a two-panel image that shows a clear before/after, problem/solution, or choice/result contrast.
- `single_panel_scene`: one clear situation designed for description, vocabulary practice, questions, or roleplay setup.

## Status Definitions

- `planned`: the image concept is planned but not generated.
- `generated`: the image file exists and has metadata in `scene-images.json`.
- `needs_revision`: the image exists but needs another generation pass or visual cleanup.
- `approved`: the image passed visual QA and is ready as a design asset.
